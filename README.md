
## Контрольные вопросы

1. JSON — текстовый формат хранения структурированных данных. Используется, чтобы сохранять объекты программы в виде читаемого текста и передавать/загружать их обратно

2. Serialize превращает объект в JSON-строку, Deserialize<T> — наоборот, восстанавливает объект из JSON-строки

3. Потому что JSON — это обычный текст. Метод не меняет сам объект, а создаёт его текстовое представление

4. File.WriteAllText("файл.json", json) — записать строку в файл; затем File.ReadAllText — прочитать её обратно и через JsonSerializer.Deserialize<T> восстановить объект

5. Да. Список объектов превращается в JSON-массив объектов [{...}, {...}]

6. Выбросится исключение JsonException

7. Данные живут между запусками, а сохранять и загружать их можно без ручной сборки строк — .NET сам превращает объекты в текст и обратно
